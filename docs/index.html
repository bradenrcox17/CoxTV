CoxTV

Live TV with a channel guide, favorites and search, on Fire TV Stick, Roku and Android phones.

Fire TV Stick Roku Android phone Updating Troubleshooting

You'll need your TV service's playlist (M3U) link. Your provider gives you this; it usually starts with http:// and is long. A guide (XMLTV) link is optional.

1 Fire TV Stick

About 10 minutes. You'll install a free app called Downloader, then use it to install CoxTV.

  1. Install Downloader

    On the Fire TV home screen, go to Find (the magnifying glass) → Search, type Downloader, and pick the orange Downloader app. Select Get or Download.

  2. Turn on Developer Options

    Go to Settings → My Fire TV → About. Highlight the first line (your device name, e.g. "Fire TV Stick 4K") and press the OK button on the remote 7 times, until it says "You are now a developer".

  3. Allow Downloader to install apps

    Press Back once to My Fire TV, open Developer Options → Install unknown apps, and turn Downloader to ON.

    Older Fire TVs show Apps from Unknown Sources instead. Turn that ON.

  4. Download CoxTV

    Open Downloader (allow access to files if it asks). In the box, type this code and select Go:

    [DOWNLOADER CODE]

    If the code doesn't work, type this address instead:
    https://github.com/bradenrcox17/CoxTV/releases/latest/download/CoxTV.apk

  5. Install

    When the download finishes, select Install, then Open. Downloader may offer to delete the install file afterward. Say Delete, since it isn't needed any more.

  6. Enter your playlist link

    The first time CoxTV opens, highlight M3U playlist URL, press OK, type your link, and choose Done. Add the guide (XMLTV) link the same way if you have one, then select Connect. Loading a big channel list can take up to a minute.

    Tip: long links are much easier to type with the free Amazon Fire TV app on your phone, which gives you your phone's keyboard.

    Have an Xtream login (server, username, password) instead? Fill in the Xtream Codes boxes on the left.

  7. Put CoxTV on your home screen

    Hold the Home button → Apps, highlight CoxTV, press the ☰ Menu button and choose Move to front.

Using CoxTV with the remote

  • Up / Down while watching: change channel
  • Left while watching: mini channel list; OK: show or hide the info bar
  • ☰ Menu (or hold OK) on a channel: add or remove a favorite
  • Sidebar: Search what's on, TV Guide, Check for updates

2 Roku

About 10 minutes. You'll need a Windows PC on the same Wi-Fi as the Roku. CoxTV isn't in the Roku Channel Store, so it's installed through Roku's Developer Mode.

  1. Turn on Developer Mode

    On the Roku remote, press this sequence (it's normal that nothing happens until the end):

    HomeHomeHome ↑↑ →←→←→

    A Developer Settings screen appears. Write down the IP address it shows (like 192.168.1.50). Choose Enable installer and restart, agree to the license, then create a password and write it down too. The Roku restarts.

  2. Download the installer on your PC

    Download the Roku installer

    If your browser warns about the file, choose Keep.

  3. Run it

    Double-click CoxTV-Roku-Installer.bat. If Windows shows "Windows protected your PC", click More info → Run anyway.

    Type the Roku's IP address and the developer password from step 1. After a few seconds you'll see SUCCESS, and CoxTV opens on your TV. The installer remembers the IP and password for next time.

  4. Enter your playlist link

    In CoxTV, select Playlist (M3U) URL, type your link, choose OK, then Save and load channels. (Have an Xtream login? Choose Enter Xtream login instead.)

    Tip: the free Roku app on your phone has a keyboard button that makes typing long links much easier.

CoxTV appears on the Roku home screen like any other channel. A Roku can hold one Developer Mode app at a time. It stays installed through restarts, but a factory reset removes it. Just run the installer again.

3 Android phone or tablet

About 3 minutes. Do this on the phone.

Download CoxTV for Android

  1. Download

    Tap the button above in Chrome (or Samsung Internet). If it says "File might be harmful", tap Download anyway.

  2. Allow your browser to install apps

    Tap the finished download (or open it from My Files → Downloads). If it says installing unknown apps isn't allowed, tap Settings, turn on Allow from this source, then go back and tap Install.

  3. Get past Play Protect

    Google Play Protect may warn you because CoxTV isn't from the Play Store. Tap More details → Install anyway. If it offers to scan the app, you can choose Don't send or Scan app; either is fine.

  4. Enter your playlist link

    Open CoxTV, paste your Playlist (M3U) link (and guide link if you have one), and tap Connect.

Watching on your phone

  • Tap a channel to watch full screen. Swipe up or down to change channel, tap to show the info bar.
  • Press Home while watching, or tap the picture-in-picture button, to keep watching in a small window.
  • Tap the heart on a channel to add it to Favorites.

Updating

Fire TV Stick & phone

CoxTV checks for updates each time it starts and offers Update now. The first time, it asks you to allow CoxTV to install apps: turn it on, go back, and the update continues. Your channels and favorites are kept.

Check anytime: Fire TV sidebar → Check for updates; phone → Settings → Check for updates.

Roku

Run CoxTV-Roku-Installer.bat again (download a fresh copy if you deleted it). Press Enter twice to reuse the saved IP and password.

Troubleshooting

Downloader says the code is invalid

Type the full address instead: https://github.com/bradenrcox17/CoxTV/releases/latest/download/CoxTV.apk

"App not installed" or "package conflicts with an existing package"

An older test copy of CoxTV is installed. Uninstall it (Fire TV: Settings → Applications → Manage Installed Applications → CoxTV → Uninstall; phone: press and hold the icon → Uninstall), then install again.

Channels won't load / connection error
  • Check the playlist link was typed completely. Long links are easy to cut short.
  • Open the link in a web browser. If it doesn't download a playlist there, contact your provider (the subscription may have expired).
  • Very large playlists (20,000+ channels) can take up to a minute the first time.
The TV guide is empty

Add your provider's guide (XMLTV) link in setup (Fire TV: Edit sources; phone: Settings → Edit sources). The guide loads in the background a minute or two after the channels. Some channels simply have no guide information.

A channel won't play or keeps stopping
  • Try another channel. Individual channels from providers go offline at times.
  • Most providers limit how many streams can play at once. Stop watching on other devices.
  • Roku only: some stream formats aren't supported by Roku players, so a few channels may play on Fire TV but not on Roku.
Roku installer: "rejected the developer password"

Run it again and type the password you created when turning on Developer Mode. Forgot it? Repeat the remote sequence from step 1 to set a new one.

Roku installer: "Could not reach a Roku"
  • Double-check the IP address (Roku: Settings → Network → About).
  • Make sure the PC and the Roku are on the same Wi-Fi/network.
  • Make sure Developer Mode is on: open http://<Roku IP> in a browser on the PC. It should ask for a password.
Windows won't run the Roku installer

On the "Windows protected your PC" screen, click More info → Run anyway. If your browser blocked the download, choose Keep in its downloads list.

Picture-in-picture doesn't work on my phone

Go to Settings → Apps → CoxTV and turn on Picture-in-picture.

CoxTV is a player app: it doesn't include any channels. Bring your own playlist from your TV service provider.
